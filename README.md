# Abaqus Tools — Full Product Website

This package contains:
- 1 catalog homepage
- 24 product detail pages
- 3 products per row on desktop
- original product numbering preserved
- products sorted from small to large
- one thumbnail/video image on every product page
- one Bilibili video button on every product page
- detailed English descriptions and feature lists
- responsive desktop/mobile layout
- robots.txt and sitemap.xml templates

## Important: Bilibili video links

Direct Bilibili video URLs were inserted where a direct URL was confidently identified.
For products where the exact BV video URL was not available from the supplied information,
the button points to a Bilibili search for that exact original Chinese product title.
You can later replace these with direct BV URLs in the corresponding HTML file or in products.json.

## Images

The supplied Bilibili CDN image URLs are used directly in the HTML.
This keeps the package small and immediately usable. For maximum long-term reliability,
download the images later into a local `images/` folder and change the `src=` paths.

## Email

Replace all instances of:
your-email@example.com

with your actual sales/support email.

## GitHub Pages

Upload the entire folder to one GitHub repository.
Enable:
Settings → Pages → Deploy from a branch → main → /(root)

Do not upload each product separately. All detail pages are part of the same website.

## Custom domain

Replace YOUR-DOMAIN.com in robots.txt and sitemap.xml after you buy a domain.
