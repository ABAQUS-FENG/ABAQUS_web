# Abaqus Tools — Full Product Website

This package contains:
- 1 catalog homepage
- 24 product detail pages
- 3 products per row on desktop
- original product numbering preserved
- products sorted from small to large
- one thumbnail/video image on every product page
- one Bilibili video button on every product page
- detailed English descriptions and feature lists
- responsive desktop/mobile layout
- robots.txt and sitemap.xml templates
