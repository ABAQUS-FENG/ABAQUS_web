DETAILS

2D Polygon Aggregate 2.0

Generate multi-graded 2D polygonal aggregates inside arbitrarily shaped matrices. Aggregate gradation, size range, area fraction, ITZ thickness and polygon side count can be customized. Aggregate and matrix are created as separate parts.

  • Multi-graded 2D polygon aggregates
  • Custom aggregate size, area ratio and polygon sides
  • Optional ITZ thickness
  • Supports circular, rectangular, triangular and custom matrices
  • Aggregate and matrix remain separate parts
  • Exportable to COMSOL, CAD and ANSYS
